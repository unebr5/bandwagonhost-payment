## 搬瓦工支持信用卡付款吗？先说结论

支持。搬瓦工的下单流程里提供了四种付款方式：**信用卡、PayPal、银联和支付宝**。其中信用卡通道底层走的是 Stripe，主流的 Visa 和 MasterCard 基本都能通过；American Express 在部分地区可以走通，但第三方教程普遍反映它的通过率不如 Visa/MasterCard 稳定。

有两点值得提前知道：

- 银联卡不能直接当信用卡刷。信用卡通道只认 Visa/MasterCard 这一类的国际卡组织，手里只有银联卡的话，要么走专门的银联通道，要么用其他付款方式。
- 有 Reddit 用户在讨论搬瓦工时提到，它在中文用户里流行的一个原因就是"接受中国银行发行的信用卡"。也就是说，国内银行发行的、带 Visa 或 MasterCard 标志的双币卡、全币卡，是可以直接付美元账单的。

## 用信用卡付款的完整流程

下单本身不复杂，整个过程大概五步：

1. **注册账号**。用常用邮箱注册，账号信息按真实情况填写。搬瓦工的服务条款明确要求账户持有人和联系方式准确，填假信息可能导致账号被封。
2. **选套餐并生成订单**。选好套餐和机房，系统生成账单。
3. **选择 Credit Card 并填卡信息**。进入付款页后选 Credit Card，依次填卡号、有效期（MM/YY）、CVV。这一步是在 Stripe 的安全页面上完成的。
4. **完成 3D Secure 验证**。多数国内银行发行的卡会跳转短信验证码或银行 App 确认，这一步不做，交易大概率会被风控挡下来。
5. **等待开通**。付款成功后回客户区，VPS 开通后可以在 KiwiVM 面板里拿到 IP 和 root 权限。

另外有一种场景要区分开：如果你不是买新套餐，而是**给账户余额充值**，路径是客户区里的 Billing → Add Funds，同样选 Credit Card 填卡信息提交即可。充值和直接购买走的是不同的入口，第一次操作别找错地方。有人用 PayPal 充值时会有最低金额要求，信用卡充值同理注意页面上标注的限额就行。

## 信用卡被拒了怎么办

"card declined"是搜这个关键词的人最常碰上的坑。被拒的原因不在搬瓦工这边，而是出卡方或支付处理方的风控，常见原因和对应做法如下：

- **卡组织不对**。确认手里的卡是 Visa 或 MasterCard。银联单标卡、JCB 在这个通道走不通，换卡比反复重试有用。
- **没完成 3D Secure 验证**。发卡行 App 里弹出的验证（Visa Secure / MasterCard Identity Check）要手动确认。有些银行默认关闭这个功能，去 App 里开一下。
- **网络环境异常**。挂代理、VPN 或 IP 与账单地址所在地差太远，都容易触发风控。用本地网络、裸连再试一次。
- **账单地址不匹配**。填的账单信息要和银行登记的一致。
- **预付卡和礼品卡**。这类卡在很多商家都容易被拒，因为预授权金额可能高于实际扣款，搬瓦工这里也不例外，尽量用正规信用卡。
- **确实被发卡行拒了**。上面都排除了还不行，直接打发卡行电话问这笔交易的状态，很多时候是他们那边拦的。

还有一个兜底方案：信用卡反复被拒，就换 PayPal 付款。这是第三方教程里提到最多的替代路径，同样即时到账，对卡的要求也绕开了。

## 付款安全：不存卡、不自动扣款

这部分是搬瓦工官方写得很明确的，值得单独拿出来说，因为它直接回答了一个高频疑虑——"绑了卡会不会被随便扣钱"。

官方续费文档的原话是：他们**从不自动扣取任何付款方式的钱，包括信用卡和 PayPal**，因为压根不保存客户的支付信息，技术上就无法自动扣款。所有付款都由用户手动发起。隐私政策里也写明，支付处理由第三方安全完成，信用卡信息不会存在搬瓦工自己的服务器上。

续费的逻辑是这样的：系统会在到期前 7 天生成新账单，账户里有钱就自动用余额抵扣，没钱就通知你，通知后有 7 天付款期，再不付才会暂停服务。不想续费，在客户区把 Renewal 关掉即可，到期后实例直接取消，不再产生账单。如果打算长期不手动操作，官方建议的玩法是提前往账户里充一笔余额，账单会自动从余额里扣。

## 和付款有关的几条规则，下单前看一眼

- **退款政策**：官方提供 30 天退款保障（部分第三方资料将其表述为 99.9% 在线率承诺之外的独立政策），但退款不是无条件的——通常要求是新订单、30 天内申请、无滥用行为、无支付争议、流量未超政策阈值。买了大流量套餐又几乎用满，退款时容易被卡。
- **账号信息要真实**。条款要求账户持有人信息准确，虚拟信息可能触发审核甚至封号，付款用的卡名字最好也和账号一致。
- **不要买卖账号**。条款明确账号不可转让或出售，二手账号的付款纠纷没有保障。
- **备份靠自己**。退款通过后服务和数据会被立即清除，续费逾期 7 天也会停机，重要数据放在 VPS 之外的备份里。
- **挖矿和滥用不碰**。条款禁止加密货币挖矿、垃圾邮件、端口扫描等行为，违反会导致服务被暂停，付款是不退的。

## 常见问题

**搬瓦工能用国内银行的双币信用卡吗？**
可以。只要卡面带 Visa 或 MasterCard 标志，付款时完成 3D Secure 验证即可，账单以美元结算。

**信用卡被拒，多试几次有用吗？**
如果原因是网络环境或没完成银行验证，修正后再试是有效的；如果卡本身不符合要求（银联单标、预付卡），换卡或换 PayPal 更快。

**会不会到期自动从我卡上扣钱？**
不会。搬瓦工不保存支付信息，技术上无法自动扣款，所有付款都由你手动完成。

**信用卡付款和 PayPal 付款，价格有区别吗？**
套餐价格一致，区别只在通道本身。选择哪个更多看你的卡和付款习惯。

**优惠码在续费时还能用吗？**
循环折扣码在续费时同样生效，这也是它和一次性促销的主要区别。
